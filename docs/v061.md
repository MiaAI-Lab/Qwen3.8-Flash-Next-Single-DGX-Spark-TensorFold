**TensorFold v0.6.1 port: what changed and what was measured (2026-10-02)**

The recipe moved from TensorFold v0.6.0 (`c464617`) to v0.6.1 (`17c73e1`). `patches/0002-flash-next-v060.patch` was
replaced by `patches/0002-flash-next-v061.patch`, and `patches/languages/0010-flash-next-draft-languages.patch` was
rebased (it had not been rebased onto v0.6.0, so `DRAFT_LANGUAGE` builds did not work there).

## The port

- Image input is now upstream's own Flash Next vision (TensorFold #146, adapted from this recipe's v0.6.0 patch),
  so the patch no longer carries the rotary kernels, image rows or stream state. It still adds video input, up to
  50 images sharing 16,384 tokens (`--vision-max-images`, `TENSORFOLD_IMAGE_TOKENS`), copy drafts, SSD read-ahead,
  first token before the next draft, no MTP logits while prompts absorb, and 96 MiB request bodies.
- The v0.6.0 setup accepted only 4 images a request: the many-images code had been dropped when the patch series was
  folded for v0.6.0. Measured: 12 images were refused on v0.6.0 and answered correctly on v0.6.1.
- A dead line in the v0.6.0 patch's `weights.py` (meant to read `mrope_section`) is gone; upstream reads it.
- `TENSORFOLD_PREFILL_ROWS` is an override of upstream's own choice (2,048 rows, or 4,096 while idle without
  vision). The recipe sets 2,048 when the n-gram tables are on SSD (see Prefill below).

## Measurements

One DGX Spark, defaults (5 x 262,144, int8 KV, `--ple-on-ssd`, vision on, MTP 6/0.60, copy drafts on). Driver and
logs were in the session scratchpad; prompts are `tools/bench.py`'s synthetic prose and natural prompts.

Admission: v0.6.0 85.18 GiB, 26.4 GiB free for caches; v0.6.1 85.39 GiB, 25.7-26.3 GiB free across boots (five
full windows need 22.4 GiB). Upstream's fused HC kernels passed their byte-exact self-check and are enabled.

**Exactness.** Greedy, 6 prompts x thinking on/off: drafted = serial (`"draft": false`) and solo = 5 concurrent on
both versions, and v0.6.1's token ids equal v0.6.0's in all 34 replies (also with `VISION=0`).

| | v0.6.0 | v0.6.1 |
| --- | ---: | ---: |
| Prefill 6.4k tok | 3.18 s | 3.14 s |
| Prefill 25k tok | 11.36 s | 11.19 s |
| Prefill 50k tok | 22.05 s | 22.05 s |
| Decode, code greedy (1 stream) | 64.2 tok/s | 63.7 tok/s |
| Decode, chat sampled (1 stream) | 52.3 tok/s | 52.0 tok/s |
| Suite, 5 streams aggregate | 95.0 tok/s | 94.4 tok/s |
| New question on a shared 31k-token system prompt | 14.2 s TTFT, 0 cached | 0.18 s TTFT, 31,421 cached |

Single runs of each; the speed differences are within run-to-run noise, the shared-prefix one is not.

**Prefill pieces (text only, `VISION=0`).** Upstream's 4,096-row idle pieces against 2,048, same image, n-gram tables
on SSD, median of 3 (the 4,096 arm on two separate boots):

| Prompt | 2,048 rows | 4,096 rows (boot 1 / boot 2) |
| ---: | ---: | ---: |
| 2.4k | 1.71 s | 1.48 / 1.51 s |
| 4.0k | 2.53 s | 2.32 / 2.36 s |
| 6.2k | 3.02 s | 4.09 / 4.12 s |
| 7.9k | 4.39 s | 4.66 / 5.38 s |
| 9.9k | 4.71 s | 5.76 / 4.98 s |
| 11.8k | 5.50 s | 6.80 / 6.12 s |
| 15.8k | 7.00 s | 7.47 / 8.22 s |
| 31.5k | 13.65 s | 14.12 / 14.14 s |

Upstream measured about 15% faster at 8k-32k, presumably with the tables in RAM; with them on SSD, 2,048 is faster
from about 5k tokens, so the recipe sets `TENSORFOLD_PREFILL_ROWS=2048` when `PLE_ON_SSD=1`.

**Capacity.** Five concurrent ~236k-token prompts (each near the full window) all completed; the lowest
`MemAvailable` during the run was 2.9 GiB. The ~195k-token needle test (`tools/needle.py`) answered correctly.

**Vision and tools.** `tools/visioncheck.py` and `tools/toolcheck.py` pass. A 4-second video of a red ball moving
right: "The moving object is red and it moves from left to right." Twelve solid-colour images: count and all twelve
colours correct (830 prompt tokens).

**Language image** (`DRAFT_LANGUAGE=zh`, drafts over 101,679 token ids): three Chinese prompts, greedy, 300 tokens,
37.5 tok/s on the default image and 55.6 tok/s on the language image (+48%), drafted = serial on both.

Not measured: the fork-resume and short-prompt-first changes beyond the shared-prefix test above, the
`TENSORFOLD_MTP_COPY` gain on v0.6.1, and image prompts mixed with long text prompts under full load.
